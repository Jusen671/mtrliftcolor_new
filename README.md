# MTR Elevator Screen Customizer

[English](#english) | [中文](#chinese)

---

<a name="english"></a>
## English

A feature-rich addon for **Minecraft Transit Railway (MTR)** that allows you to fully customize your elevator cabin screens. Say goodbye to monotonous elevators!

### 🌟 Features
*   **Screen Coloring:** Change the font color of the elevator screen using **Hex codes** or an in-game **color slider**.
*   **Arrow Customization:** Modify arrow size, and adjust vertical/horizontal offsets.
*   **Maintenance Modes:** Includes检修 (Maintenance) mode and various other display states.
*   **Smart Dispatch:** Supports a dispatch system based on JSON configuration files.
*   **Cross-Platform:** Fully compatible with PC and mobile (Tested on FCL Launcher).
*   **Bilingual:** Supports both English and Chinese.

### 📥 Installation
*   **Required on both Client and Server.** (Must be installed on both sides to function correctly).
*   Requires **Minecraft Transit Railway (MTR)** mod.

### ⚙️ Configuration
*   Colors can be adjusted via the GUI (Hex input or sliders).
*   Dispatch rules can be modified through external **JSON files**.

<a name="chinese"></a>
## 中文

一个为 **Minecraft Transit Railway (MTR)** 设计的功能丰富的扩展模组，让您可以修改电梯轿厢屏幕。告别单调的电梯！

### 🌟 功能特性
*   **屏幕染色：** 通过 **Hex代码** 或游戏内的 **颜色滑块** 更改电梯内部显示屏的字体颜色。
*   **箭头修改：** 自定义箭头大小，并支持上下、左右偏移调整。
*   **检修模式：** 支持检修模式及电梯运行模式切换(不是屏幕)。
*   **分梯机制：** 支持基于 **JSON文件** 的自定义分梯逻辑。
*   **多平台适配：** 完美兼容电脑端和手机端（已在 FCL 启动器 测试）。
*   **双语支持：** 支持中文和英文界面。

### 📥 安装说明
*   **客户端与服务端必装。**（两端均需安装才能正常工作）。
*   需要前置模组 **Minecraft Transit Railway (MTR)**。

### ⚙️ 配置文件
*   颜色可通过 GUI 界面调整（Hex输入或滑块）。
*   分梯机制可通过外部 **JSON文件** 进行修改。
